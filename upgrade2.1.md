# WEBSITE UPGRADE 2.1
## Dynamic Registration System + Admin Form Builder

---

# PRIMARY GOAL

Convert the website into a professional Yoga Institute Management Platform.

The registration form MUST NOT be hardcoded.

Instead, create a Dynamic Form Builder inside the Admin Dashboard so the institute owner can create, edit, reorder, hide, duplicate, archive and publish forms without modifying code.

The existing website design must remain unchanged.

---

# CRITICAL RULES

- Never break existing UI.
- Never redesign pages.
- Keep SEO intact.
- Keep performance optimized.
- Build reusable components.
- Mobile First.
- Future proof architecture.

---

# MAIN REQUIREMENT

Create a Form Builder CMS.

The admin should NEVER need a developer to modify the admission form.
