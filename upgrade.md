# Iti Iti Yogashram Website Upgrade Plan

## Objective

Upgrade the existing website into a premium international yoga platform without breaking the current UI, UX, SEO, routing, responsiveness, or existing functionality.

---

# CRITICAL RULES

1. Preserve the existing design language.
2. Do NOT redesign the website.
3. Reuse existing components whenever possible.
4. Maintain responsive behavior.
5. Do not remove any current functionality.
6. Follow accessibility standards.
7. Optimize Core Web Vitals.
8. Keep all pages SEO-friendly.
9. Add structured schema wherever applicable.
10. Every new feature must degrade gracefully.

---

# Priority Order

Priority 1 → Trust

Priority 2 → Conversion

Priority 3 → Student Experience

Priority 4 → Future Scalability
